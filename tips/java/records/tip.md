A record is a special kind of class. It is a blueprint for creating objects. You can make a record for a person with a name and age. You write the record name and the fields in parentheses. Java adds a constructor, getters, equals, hashCode and toString for you. This makes your code shorter and safer. You would use a record when you need a simple class with mostly data.
