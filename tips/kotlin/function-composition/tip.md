Function composition lets you combine two or more functions into one. It takes the output of one function and uses it as the input of the next. First, define two simple functions. Then, compose them. The result is a new function. Use it when you need to process data in steps. For example, you might have a function that takes a string and returns its length. Another function takes a number and returns its square. You can compose these to get a function that takes a string and returns the square of its length.
