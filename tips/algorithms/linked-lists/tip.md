A linked list is a way to store data in a line. Each item points to the next. You can add or remove items easily. Think of a playlist. You can insert a new song anywhere. You can also delete a song without shifting others. It's great for dynamic collections. The first item is the head. The last item points to nothing. This is the tail. You can traverse the list from head to tail. Each item has data and a link to the next.
